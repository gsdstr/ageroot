# Agentic Stack

Control repository for personal, drop-in agent infrastructure.

## Contents

- `as_template/` — copyable project template: agent instructions, protocols,
  skills, and memory skeleton.
- `as_memory-skills/` — development source and tests for memory-lifecycle
  skills.
- `docs/agents/` — local issue-tracking, triage, and domain-documentation
  conventions.

## Use

Copy `as_template/` into a new repository, then customize its personal
preferences and project memory under `.agents/`.
